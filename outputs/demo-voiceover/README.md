## Наложение

```
D:\Temp\demo-voiceover\mix-demo-voiceover.cmd "C:\path\to\demo-video.mp4"
```

Результат — `<имя>-voiced.mp4` рядом с исходником. Звук исходника глушится
полностью (в нём нет музыки), голос микшируется в AAC 160 kbps, видео
копируется без перекодирования.

## Если видео короче 3:05

Варианты по убыванию качества результата:

1. **Доснять 25 секунд** — самый чистый путь. Запись стенда обычно идёт
   дольше, чем ожидаешь: ответ модели 20–30 с сам по себе.
2. **Убрать `demo-f4` (20.3 с)** — кусок про самопроверку. Это самый
   «технический» фрагмент, его потеря меньше всего бьёт по рассказу; гейт
   всё равно будет виден на экране. Тогда сумма 2:45 и карту сдвигаем
   вручную.
3. **Ускорить видео** до 0.89× (2:45 → 3:05). Не рекомендуется: голос
   остаётся натуральным, а картинка становится дёрганой.

## Если Fish ответил не тот голос

Голос задаётся `reference_id` в `/api/tts` (`_fish_reference()` в
`src/api/voice.py`). Чтобы переозвучить другим голосом — меняется
переменная окружения с reference, файлы генерируются тем же скриптом
(`/root/voiceover.py` на sage-pl).

## Проверка перед наложением

Прослушать `demo-f1.mp3` и `demo-f9.mp3`: первый задаёт впечатление,
последний — закрывает. Если в них слышны артефакты (обрезанное слово,
неверное ударение в «пресейл»), перегенерировать именно этот фрагмент —
дешевле, чем клеить заново.
