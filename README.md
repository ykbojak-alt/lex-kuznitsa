# ИИкузница — агент, который отвечает по регламентам и умеет сказать «не знаю»

Один агент принимает вопрос сотрудника по корпоративным документам и отвечает
многошаговым циклом: разбирает вопрос, ищет по нескольким каналам, определяет
действующую редакцию, разрешает противоречия или обоснованно отказывается —
с цитатами и журналом каждого шага.

**Стек:** Python + FastAPI, гибридный поиск (BM25 + векторный + reranker),
LLM через NexusLink (основной путь) или локальную Qwen3-8B (fallback).

**Статус:** PREP phase — код продукта не пишется до старта спринта
26.11.2026 10:00 МСК.

## Быстрый старт (5 команд)

```bash
# 1. Корпус (детерминированный, seed фиксирован)
python demo/gen-sample-corpus.py --count 20 --seed 20261126 --clean

# 2. Preflight: окружение, корпус, вопросы
sh scripts/preflight.sh

# 3. Проверка конвейера без LLM (индексация → поиск → сверка)
sh demo/run-local.sh

# 4. Профиль модели: адрес и слот шлюза — только через env
export NEXUS_LINK_BASE_URL=... NEXUS_LINK_MODEL=...

# 5. Стенд (появится на старте спринта)
python -m uvicorn src.main:app --port 8874
```

> Команды 1–3 работают уже сейчас. Команды 5 требует кода, который пишется в
> спринте; 4 — переменные, а не код.
