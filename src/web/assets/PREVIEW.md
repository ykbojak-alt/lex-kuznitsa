# LEX UI assets

- `logo-lex.svg` — гранёный обсидиановый знак LEX с тонким текстовым следом и cyan-контуром.
- `icon-accept.svg` — приём запроса: конверт и входящая стрелка.
- `icon-decompose.svg` — разветвление запроса на подзадачи.
- `icon-retrieve.svg` — поиск и извлечение источников.
- `icon-permissions.svg` — проверка доступа: закрытый замок.
- `icon-resolve.svg` — выбор действующей редакции: часы.
- `icon-conflict.svg` — сопоставление конфликтующих направлений.
- `icon-compose.svg` — сборка ответа из нескольких слоёв.
- `icon-verify.svg` — самопроверка ответа в защитном щите.
- `texture-obsidian.svg` — повторяемая гранёная подложка; использовать с общей opacity 0.03–0.05.
- `gloss.svg` — вертикальный стеклянный блик: белый 6% сверху до прозрачного.

Все файлы — текстовый SVG с `viewBox`, без растровых встроек, внешних ссылок и шрифтов. Шаговые иконки используют `currentColor`; брендовый cyan у знака задан как CSS-переопределяемый `currentColor`.
