# Demo — локальный прогон

Демо: локальный RAG-ответ по корпусу документов без внешних LLM API.

## Предусловия

- Windows 10/11 x64
- Python 3.11+ (`python --version`)
- NVIDIA GPU 8 GB VRAM (RTX 3050 target) + актуальный драйвер
- 10 GB свободного места на D:
- Ollama установлен или llama.cpp server подготовлен (см. `docs/MODEL.md`)

## 5 команд для локального прогона

> Выполнять из корня репозитория (каталог, в котором лежит этот `demo/`)

```powershell
# 1) Создать venv и установить зависимости
python -m venv .venv; .\.venv\Scripts\Activate.ps1; pip install -r requirements.txt

# 2) Поднять локальную модель (вариант Ollama)
ollama pull qwen3:8b

# 3) Построить индекс по корпусу
python .\src\index_corpus.py --corpus .\sample-corpus --out .\.cache\index

# 4) Запустить демо-запрос (CLI)
python .\src\ask.py --index .\.cache\index --model qwen3:8b --q "Какие ключевые факты есть в корпусе?"

# 5) (Опционально) Запустить демо-стенд UI
python .\demo\demo_stand.py
```

## Ожидаемый результат

- Команда 3 создаёт локальный индекс в `.cache/index`.
- Команда 4 печатает ответ и список источников (файлы/фрагменты).
- Команда 5 поднимает локальный демо-стенд (URL выводится в консоль).

## Если что-то пошло не так

| Симптом | Проверка |
|---|---|
| `ollama: command not found` | Установить Ollama, перезапустить терминал |
| CUDA/VRAM ошибка | Уменьшить контекст `-c 4096`, закрыть GPU-процессы |
| Пустой индекс | Проверить, что `sample-corpus/` содержит документы |
| Медленный ответ | Норма для 8 GB; проверить, что inference идёт на GPU (`ngl`) |

## Примечание

Имена скриптов `src/index_corpus.py`, `src/ask.py` — целевые для спринта; если структура меняется, обновить этот README в том же коммите.
