# DEMO-VIDEO-PROMPT.md — производственный промпт демо-видео LEX

**Статус:** pre-sprint материал. Написано 2026-11-25, до старта спринта
(26.11.2026 10:00 МСК — 28.11.2026 10:00 МСК). Код продукта не пишется до старта.

**Что это.** Производственная спецификация видео: как из снятого материала получается
финальный файл. Здесь — не «что говорить» (это `docs/DEMO-SCRIPT.md`) и не «что
показывать в питче» (это `docs/PITCH-VIDEO.md`), а **как оформить**: где реальный
скринкаст, где наложение титров, где генеративные вставки, в каком тайминге и в каком
техническом формате.

**Чего этот документ не делает:**

- не придумывает сцены — сцены берутся 1:1 из `docs/DEMO-SCRIPT.md` (7 сцен, 3:20 полная
  версия, 2:50 сжатая);
- не заменяет раскадровку `docs/VIDEO-STORYBOARD.md` (та — под 3:00, один непрерывный
  дубль; здесь — оформление того же материала);
- не описывает устный питч — `docs/PITCH-SCRIPT.md`.

## 0. Принцип производства: три слоя

Положение требует «одно непрерывное демо-видео на данных задачи». Значит тело видео —
**реальный прогон LEX без склеек**. Всё остальное — оформление поверх него, которое
не маскирует прогон, а делает его читаемым.

| Слой | Что это | Чем делается | Можно ли менять тело видео |
|---|---|---|---|
| **Тело** | один непрерывный скринкаст прогона LEX (сцены 0–7 по `DEMO-SCRIPT.md`) | OBS / ffmpeg gdigrab, 1080p | **Нет.** Склейка тела = дисквалификация по духу Положения |
| **Оформление** | титры, счётчик шагов `[N/7]`, переходы между сценами, финальная плашка SHA | Remotion (основной) / HyperFrames (fallback) | Нет — накладывается поверх, тело не режется |
| **Вставки** | вводка 0:00–0:15 и аутро 0:05 | Dola / Agnes Video 2.5 Flash (генерация), либо статичная плашка | Это **отдельные клипы до и после** тела, не внутри него |

**Правило честности:** между вводкой и телом — жёсткая граница «начинается реальный
прогон» (титр, не переход-растворение). Зритель должен видеть, где кончается оформление
и начинается живой стенд.

**Если Remotion не поднимется до срока** (известный блокер: `remotion browser ensure`
обрывает загрузку Chromium): fallback-порядок — HyperFrames (та же кодовая база
композиций) → ffmpeg `drawtext`/`overlay` для титров и счётчика. Оформление не должно
блокировать сдачу: голый честный скринкаст с минимумом титров лучше, чем отсутствие видео.

## 1. Технические параметры финального файла

| Параметр | Значение | Почему |
|---|---|---|
| Разрешение | 1920×1080 (16:9) | скринкаст терминала/UI читается; жюри смотрит на десктопе |
| Частота кадров | 30 fps (тело можно 30, вставки 24–30 и нормализовать) | единый таймлайн без дёрганья |
| Кодек | H.264 High, `yuv420p` | максимальная совместимость плееров жюри |
| Контейнер | MP4, `+faststart` | проигрывается до полной загрузки |
| Битрейт | VBR, целевой ~8–12 Мбит/с | текст на экране без артефактов |
| Аудио | AAC, 48 кГц, стерео; голос −16 LUFS, true-peak ≤ −1 dBTP | разборчивость, без клиппинга |
| Длительность | полная ≤ 3:20 (репетиция), сдаточная **≤ 3:00**, цель 2:50 | лимит Положения — 3 минуты |
| Размер файла | ≤ 100 МБ | удобная загрузка в форму сдачи |
| Имя файла | `lex-demo-<sha8>-<YYYYMMDD>.mp4` | SHA привязан к прогону |

**Титры должны быть читаемы при просмотре на 720p и на телефоне:** минимальный кегль —
не мельче, чем строка терминала в теле; контраст ≥ 4.5:1; плашка под текстом
полупрозрачная, чтобы текст не терялся на светлом UI.

## 2. Dola / Agnes: промпты для вводки и аутро

Вставки — единственное, где уместна генерация. Обе — без людей, без лиц, без текста
внутри сгенерированного кадра (весь текст накладывает Remotion поверх), длиной 5–15 с.

Формат промпта — 8 блоков по канону Dola-референса (визуал → параметры → фон →
хореография → камера → эффекты → запреты → стиль). Промпт подаётся как есть в Dola;
если Dola недоступна — тот же текст идёт в Agnes Video 2.5 Flash (nexuslink).

### 2.1. Вводка (intro, 0:00–0:15) — «LEX»

```
1. ВИЗУАЛЬНЫЙ РЕФЕРЕНС
   Абстрактная эмблема-знак: латинская буква «L», стилизованная как корешок
   кодекса/книги законов; рядом — тонкая вертикальная линия-«закладка».
   Без персонажей, без лиц. Геометрия чистая, векторная.

2. ФОРМАТ И ПАРАМЕТРЫ
   16:9, 15 секунд, 30 fps. Палитра: глубокий графит (#1a1d23) фон,
   знак — тёплый белый (#e8e4da), акцент — один тон (#c8a24a),
   холодная подсветка (#5b8fb9) на деталях. Мягкий студийный свет.
   БЕЗ текста, логотипов сторонних брендов, водяных знаков.

3. ФОН
   Тёмное матовое поле с еле заметной сеткой тонких линий (как лист
   миллиметровки под увеличением), глубина за счёт мягкого виньетирования.

4. ХОРЕОГРАФИЯ ПО СЕКУНДАМ
   0–3 с: из темноты медленно проявляется знак «L», линии прорисовываются.
   3–8 с: знак стабилизируется, вокруг него расходятся 2–3 тонких концентрических
          импульса (как круги по воде), гаснут.
   8–12 с: справа подтягивается вертикальная линия-закладка, встаёт на место.
   12–15 с: знак держится статично, лёгкая пульсация акцентного тона.

5. КАМЕРА
   Очень медленный наезд (push-in) с 100% до 108% за 15 с; в финале — микро-
   параллакс, камера не статична, но без тряски.

6. СПЕЦЭФФЕКТЫ
   Тонкое свечение по контуру знака; частицы-«пылинки» в световом конусе
   (5–7 штук, медленные); без искр, без глитча, без агрессии.

7. ЗАПРЕТНЫЙ СПИСОК
   ❌ любой текст/надписи/цифры в кадре; ❌ люди, лица, руки;
   ❌ сторонние логотипы; ❌ водяные знаки; ❌ сильное размытие движения;
   ❌ смена цветовой схемы между кадрами; ❌ резкие склейки.

8. СТИЛЬ
   Спокойный корпоративный техно-минимализм: матовые поверхности, точная
   геометрия, сдержанная палитра, «дорого и тихо». Не крипто-неон, не гейм-стиль.
```

**Титр поверх вводки (накладывает Remotion, не Dola):**

- 0:02–0:12, по центру-ниже знака: **`LEX`** (крупно), под ним **«отвечает по регламентам и умеет сказать „не знаю"»** (мельче).

### 2.2. Аутро (outro, 0:05) — плашка результата

```
1. ВИЗУАЛЬНЫЙ РЕФЕРЕНС
   Тот же знак «L» из вводки — преемственность. Ничего нового.

2. ФОРМАТ И ПАРАМЕТРЫ
   16:9, 5 секунд, 30 fps. Та же палитра, что в вводке.

3. ФОН
   Тот же графитовый фон, виньетка.

4. ХОРЕОГРАФИЯ ПО СЕКУНДАМ
   0–2 с: знак «L» в центре, концентрические импульсы затухают.
   2–5 с: знак медленно уходит в лёгкую тень, поле остаётся ровным — место
          под титр (текст наложит Remotion).

5. КАМЕРА
   Статичная, без движения (в отличие от вводки) — кадр «выдоха».

6. СПЕЦЭФФЕКТЫ
   Только мягкое затухание свечения контура к финалу.

7. ЗАПРЕТНЫЙ СПИСОК
   ❌ текст в кадре; ❌ люди; ❌ движение камеры; ❌ резкие эффекты.

8. СТИЛЬ
   Тот же корпоративный техно-минимализм, финальный «выдох».
```

**Титр поверх аутро (Remotion):**

- `LEX · локальный контур · <N> документов в индексе` (строка 1);
- `commit <sha8>` (строка 2, моноширинным).

> **Альтернатива без генерации:** если Dola/Agnes недоступны или генерация не уложилась
> в срок — вместо вводки/аутро ставится статичная плашка (тёмный фон + тот же знак,
> собранный в Remotion/HyperFrames). Видео от этого не становится хуже по существу —
> теряется только «дорогая» анимация. **Тело видео (прогон LEX) не страдает никогда.**

## 3. Remotion: спецификация оформления

Оформление = отдельный Remotion-проект, который берёт готовый скринкаст как
`<OffthreadVideo src={staticFile('lex-raw.mp4')} />` и накладывает поверх слои по
таймкоду. Тело видео не режется, не ускоряется, не переставляется.

### 3.1. Структура

```
src/
  Root.tsx                  // registerRoot + <Composition> для двух версий
  DemoFull.tsx              // полная 3:20
  DemoShort.tsx             // сжатая 2:50
  layers/
    ProgressCounter.tsx     // счётчик шагов [N/7] в правом нижнем углу
    SceneTitle.tsx          // крупный титр сцены (верх-лево, fade in/out)
    Caption.tsx             // нижняя строка-подпись (что идёт сейчас)
    Boundary.tsx            // жёсткая граница «дальше — реальный прогон»
    Outro.tsx               // плашка SHA/документов поверх аутро
  timing/
    scenes-full.ts          // массив { id, startFrame, endFrame, title, caption, step }
    scenes-short.ts
public/
  lex-raw.mp4               // снятое тело
  intro.mp4                 // из Dola/Agnes или статичная плашка
  outro.mp4
```

### 3.2. Компоненты и поведение

**`ProgressCounter`** — счётчик `[N/7]` в правом нижнем углу, виден на сценах 2–4.

- Появляется с шага 1 (`decompose`), меняется по таймлайну, не по OCR кадра:
  тайминги шагов заранее известны из прогона и записаны в `scenes-*.ts`.
- Кегль крупный (читаем на телефоне), моноширинный, полупрозрачная тёмная плашка.
- **Важно:** счётчик дублирует то, что уже видно в UI, — он для читаемости при сжатии,
  а не подмена. Если на видео шаг виден, а счётчик отстаёт — счётчик подчиняется видео.

**`SceneTitle`** — крупный титр вверху слева, 1–2 слова: `Вводка`, `Запуск`,
`Разбор и поиск`, `Действующая редакция`, `Ответ с цитатой`, `Отказ`, `Аналитика`.
Fade in 12 кадров / hold / fade out 12 кадров.

**`Caption`** — нижняя строка (полупрозрачная плашка), держит одну мысль сцены.
Текст — в §4. Fade in/out по 10 кадров, никогда не перекрывает поле вопроса и область
ответа (проверять по кадрам, где UI занят).

**`Boundary`** — на стыке вводки и тела (около 0:15): короткий титр
**«дальше — реальный прогон, без монтажа»**, 2 с, затем исчезает. Это защита честности.

**`Outro`** — плашка с SHA и числом документов поверх аутро-клипа.

### 3.3. Переходы

- Вводка → тело: **не** кроссфейд. Cut + `Boundary`-титр. Зритель должен видеть шов.
- Между сценами внутри тела: **без переходов**. Тело непрерывно, никаких `TransitionSeries`
  внутри прогона. Допустим только лёгкий fade титров `SceneTitle`/`Caption`.
- Тело → аутро: cut после остановки стенда.

> Если очень нужен `TransitionSeries` — только между вводкой и аутро как отдельными
> клипами вне тела. Внутри тела переходов нет.

### 3.4. Рендер

```bash
# из каталога Remotion-проекта, тулкит уже стоит локально
npx remotion render DemoShort out/lex-demo-short.mp4 --codec=h264
npx remotion render DemoFull  out/lex-demo-full.mp4  --codec=h264

# финальная нормализация звука и faststart через ffmpeg
"D:\tools\ffmpeg\ffmpeg.exe" -i out/lex-demo-short.mp4 \
  -c:v copy -c:a aac -b:a 192k -af "loudnorm=I=-16:TP=-1.0:LRA=11" \
  -movflags +faststart out/lex-demo-final.mp4
```

`loudnorm` — чтобы голос совпал по громкости с вводкой/аутро; иначе на стыке скачок.

## 5. Сжатая версия 2:50 (сдаточная, лимит 3:00)

Логика резки — из `DEMO-SCRIPT.md` §3 (сцены 3, 4, 5 не трогаем). Что меняется в
**оформлении**:

| Сцена | Оформление в сжатой версии |
|---|---|
| Вводка (Dola) | 0:00–0:12: intro-клип короче, подзаголовок без второй строки |
| 0 Вводка стенда | `SceneTitle` без `Caption`; только SHA + `profile: local` |
| 1 Запуск | индексация молча; `SceneTitle` «Запуск», без `Caption` |
| 2 Разбор | `ProgressCounter` 1→3, `Caption` одна строка, числа назвать один раз |
| 3 Редакция | **без изменений** — ядро; `ProgressCounter` 4, `Caption` как в полной |
| 4 Ответ | **без изменений** |
| 5 Отказ | **без изменений** — второй по силе кадр |
| 6 Аналитика | два блока вместо пяти; `Caption` одна строка |
| 7 Закрытие | только `Outro`-плашка SHA, без аутро-клипа Dola (экономия 5 с) |

**Правило:** резка — только титры и вводка/закрытие. Тело прогона в сценах 3–5 не
ускоряется и не вырезается.

## 6. Числа в титрах и на кадре: placeholder-политика

Числа в титрах (`<N> документов`, шаг-счётчик) — **из фактического прогона**, не
выдуманные. В спецификации ниже — пример из `DEMO-SCRIPT.md`, помеченный как пример:

| Место | Пример (НЕ утверждать без прогона) | Источник правды |
|---|---|---|
| Вводка/аутро: число документов | `20` | вывод индексатора в прогоне |
| Счётчик `[N/7]` | 1–7 по таймлайну шагов | `scenes-full.ts` из журнала прогона |
| Сцена 2: выдача | `BM25 12 · vector 10 → rerank 5` | лог шага `retrieve` |
| Сцена 3: редакции | `СР01-Р1/Р2/Р3` с датами | вывод `resolve` |
| Сцена 6: аналитика | отказы/неудачи/покрытие | агрегат журнала |

**Запрещено:** ставить в титр число, которого не было в этом прогоне. Если прогон дал
другое число — титр меняется под прогон, а не наоборот.

## 7. Запреты (сводно)

1. **Не склеивать тело прогона.** Ни `TransitionSeries`, ни cut внутри сцен 0–7.
2. **Не подменять ответы.** Титры не содержат заранее заготовленных ответов на вопросы,
   которые прогон не задавал.
3. **Не маскировать профиль.** `profile: local` и SHA видны в кадре, не заклеены титром.
4. **Не рисовать PASS/зелёные бейджи**, которых не было в прогоне.
5. **Секреты/ключи/домашние пути** — вне кадра (проверять историю shell до записи).
6. **Не обещать в титрах** «production-ready», «полная интеграция», «100% точность».
7. Текст в титрах — **по-русски**, коротко (одна мысль на плашку), контраст ≥ 4.5:1.

## 8. Чек-лист готовности оформления

- [ ] Тело снято одним дублем, `lex-raw.mp4` без склеек (см. `DEMO-SCRIPT.md` §4 стоп-условия).
- [ ] `scenes-full.ts` / `scenes-short.ts` совпадают с фактическими таймингами записи.
- [ ] `ProgressCounter` не расходится с тем, что видно в UI (проверено по кадрам).
- [ ] Вводка/аутро готовы (Dola/Agnes или статичная плашка) — не блокируют сдачу.
- [ ] `Boundary`-титр на стыке вводки и тела присутствует.
- [ ] Финальный файл: 1080p, 30fps, H.264, `+faststart`, ≤ 3:00, ≤ 100 МБ, голос −16 LUFS.
