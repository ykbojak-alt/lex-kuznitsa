## 3. Видео

### 3.0. Требования организатора к самой форме сдачи (Положение, 27.11.2026)

Поле «Демо-видео» в заявке — **обязательное**. В него вставляют ссылку,
начинающуюся с `http://` или `https://`. **Видео должно открываться по ссылке
без запроса доступа** — если плеер просит вход, заявка не принимается.

| | Требование |
|---|---|
| 🟢 Надо | продолжительность **до 3 минут** (не «3–4», см. V1 ниже); запись **одним фрагментом, без монтажа**; на видео показана **работа продукта на данных задачи**; видео отражает **фактическую работу продукта** — направляя продукт, это подтверждается |
| 🟢 Можно | ускорять фрагменты ожидания ответа модели; субтитры, подписи, стрелки-пояснения; голосовой комментарий; окно с камерой в углу; запись не во весь экран, а окна приложения или нужной области |
| 🔴 Нельзя | склейки, нарезку и **любой монтаж** — видео должно быть одним фрагментом; длиннее 3 минут; заменять показ работы презентацией или слайдами; показывать функциональность, которой в продукте нет |

**Следствие для нашего материала.** Не успели что-то — пишется в описании в
графе нереализованной функциональности (`docs/LIMITS.md`, `docs/ONE-PAGE.md`),
а не показывается в кадре. Ускорение ожидания — единственная допустимая
правка времени; всё остальное, что меняет кадр, — монтаж.

### 3.1. Критерии видео

| ID | Критерий | Как проверяем | Статус |
|---|---|---|---|
| V0 | **Ссылка открывается без запроса доступа** | открыть в приватном окне браузера без авторизации: плеер играет, входа не просит | [ ] |
| V1 | **Длительность до 3:00** | Тайминг финального ролика ≤ 3:00. Источник — Положение; прежняя редакция этого пункта («3–4 минуты») была неверна и отменена 27.11. | [ ] |
| V2 | **Все кадры из VIDEO-STORYBOARD** | Финальный ролик покрывает сцены/кадры, описанные в `docs/VIDEO-STORYBOARD.md`; отклонения зафиксированы. | [ ] |
| V3 | **Один фрагмент / честный прогон** | Нет склеек, нарезки и любого монтажа; запись начинается до запуска и заканчивается после остановки/вывода результата. Ускорено может быть только ожидание ответа модели. | [ ] |
| V4 | **Видны ключевые доказательства** | На экране видны: режим/контур inference, запрос, найденные источники, ответ, отказ/конфликтный кейс (если в сценарии), итог. | [ ] |
| V5 | **Нет показа несуществующего** | В кадре нет функциональности, которой в продукте нет; нереализованное перечислено в описании, не в видео. | [ ] |

## 4. Gate перед сдачей

Сдача разрешена только если:
- все P1–P4 подтверждены фактическим прогоном;
- R1–R8 присутствуют в репозитории и актуальны;
- V0–V5 выполнены, либо отклонения явно описаны в `docs/LIMITS.md` / отчёте сдачи;
- в материалах нет секретов, приватных ключей, персональных данных и необоснованных заявлений.
