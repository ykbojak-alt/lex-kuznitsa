## 4. Ограничение: история git

**Важно понимать:** перенос в `docs/legacy/` + `.gitignore` убирает файлы из
**текущего состояния** ветки, но не из **истории коммитов**. Если репозиторий
уже публиковался, любой желающий может достать файл из ранних коммитов.

Для полного удаления из истории нужен один из инструментов:

```bash
# Вариант A: git filter-repo (рекомендуется)
git filter-repo --path docs/IIKUZNITSA-APPLICATION-DRAFT.md \
                --path docs/IIKUZNITSA-QUESTIONS-TO-ORGANIZERS.md \
                --path docs/IIKUZNITSA-MOTIVATION.md \
                --path docs/IIKUZNITSA-REPO-AND-DESCRIPTION.md \
                --invert-paths

# Вариант B: если репозиторий ещё не публиковался —
# просто создать чистую ветку и опубликовать её
```

**Рекомендация:** если репо ещё приватно и не публиковалось — достаточно
текущей очистки. Если публиковалось — прогнать `git filter-repo` перед сдачей
и force-push.
