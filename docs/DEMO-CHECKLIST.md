# DEMO-CHECKLIST — прогон демо-видео LEX перед записью

> **Назначение:** единый чек-лист, по которому прогоняют демо перед съёмкой.
> Тайминг: **3–4 минуты** (см. также `docs/DEMO-SCRIPT.md`).
>
> **Фикстуры для сцен:** `docs/DEMO-FIXTURES.md`.
> **Связь с кодом:** профиль работы — локальная модель, `profile: local`; основной
> путь инференса — NexusLink (сервер), локальная модель Qwen3-8B — fallback
> (см. `docs/DEPLOY-NEXUSLINK.md`).

---

## Чек-лист

### 1. Что должно работать (функционал)

| # | Проверка | Как проверяем | Ожидаемый результат |
|---|----------|---------------|---------------------|
| 1 | Дубль end-to-end без склеек | один запуск: `run → status → report` | история в терминале непрерывна |
| 2 | Профиль локального инференса | `cat config.toml` / аналог | `profile: local` видно в кадре |
| 3 | Ссылки на источники | ответ со ссылкой на корпус | ссылки работают (файл существует) |
| 4 | Отказы корректны | фикстура 4 (`docs/DEMO-FIXTURES.md`) | обоснование + ссылка на противоречие |
| 5 | Аналитика журнала | фикстура 5 | 3–5 выводов с цитатами из записей |
| 6 | Конфликт редакций | фикстура 3 | две позиции с буквальными цитатами |
| 7 | Нет секретов в кадре | `git status`-like прогон перед съёмкой | нет ключей, паролей, домашних путей |

### 2. Что должно быть в кадре (сценарий, 3–4 мин)

| Сцена | В кадре | Реплика (эскиз) |
|---|---|---|
| 0 | пустой терминал + SHA крупно + `profile: local` | «Это LEX… сеть выключена. Запись началась до запуска — сейчас покажу три вещи: ответ со ссылкой, отказ, аналитику» |
| 1 | запуск + вопрос (фикстура 1) | ответ со ссылкой + подтверждение цифр |
| 2 | расчёт (фикстура 2) | число + порядок расчёта |
| 3 | конфликт редакций (фикстура 3) | две позиции, вердикт «две редакции друг от друга не разделены» |
| 4 | обоснованный отказ (фикстура 4) | «не могу ответить» + цитаты из документа |
| 5 | аналитика журнала (фикстура 5) | выводы + краткие цитаты |
| 6 | мини-прогон: `run → status → report` | статус/отчёт в кадре |
| 7 | закрытие (опц.) | коротко: что показано и ограничения |

### 3. Тайминг (цель 3:00–3:30, лимит 3:00)

| Сек | Сцена |
|-----|-------|
| 0:00–0:20 | Сцена 0: вводка (экран пустой, SHA, `profile: local`) |
| 0:20–0:40 | Сцена 1: факт (запуск, вопрос, ответ со ссылкой) |
| 0:40–1:10 | Сцена 2: расчёт (число, порядок расчёта) |
| 1:10–1:50 | Сцена 3: конфликт редакций (две позиции) |
| 1:50–2:20 | Сцена 4: обоснованный отказ (цитаты из документа) |
| 2:20–2:50 | Сцена 5: аналитика журнала (3–5 выводов) |
| 2:50–3:00 | Сцена 6/7: короткое завершение, опционально мини-прогон |

### 4. Запись

| Шаг | Что делаем |
|-----|-----------|
| До записи | запускаем сетевой монитор: нет исходящих вызовов до старта |
| Запись | один непрерывный дубль, нет склеек |
| После | прогон по чек-листу пункт 1–7 в том же дубле; фиксируем, что работает |
| Размонтаж | только для обрезка хвоста/начала (запрещено — см. `docs/DEMO-SCRIPT.md`), повтор снимка при правке |
