  «21.1. За анкетирование заказчика о качестве выполненного проекта отвечает
  Менеджер по качеству. Для сервисных проектов анкетирование проводится ежеквартально.»
* `КД-ПД-01`, раздел «22. Анкетирование заказчика о качестве выполненного проекта»:
  «22.1. За анкетирование заказчика о качестве выполненного проекта отвечает

**Не должно быть:** выдуманных сроков, сведений о документах, которых нет в
корпусе, и ответа без единой цитаты. Оговорку (`medium`) с экрана **не убирать**.

## C-1 — акт В: ответ СК → кейс → повторный вопрос отвечен из кейса

Три шага, все проверены:

**Шаг 1 — служба качества отвечает.** В очереди СК открыт тикет из B-1; ответ
вводится вручную (в демо — так и должно быть: человек, а не агент):

> «Первичные бухгалтерские документы хранятся пять лет со дня составления.»

`POST /api/tickets/{tid}/answer` → тикет получает `status: answered`.

**Шаг 2 — кейс появился в базе.** `GET /api/cases`:

| Поле | Значение |
|---|---|
| `id` | `case-0001` |
| `question` | «Какой срок хранения первичных бухгалтерских документов?» |
| `answer_in_practice` | «Первичные бухгалтерские документы хранятся пять лет со дня составления.» |
| `author_role` / `author_name` | `quality` / «служба качества» |
| `outcome` | `resolved` |
| `source` / `escalation_id` | `escalation` / `esc-0001` |
| `linked_docs` / `rule_key` | пусто — регламент этого не покрывает |
| `normative` | `false` — кейс не нормативен |

**Шаг 3 — тот же вопрос, новая сессия.** `POST /api/ask` с тем же текстом:

| Шаг | Кадр |
|---|---|
| 5 `retrieve` | «предмет 33% · близость 0.48 · предмет вопроса не найден (33%) · **тема закрыта кейсом из практики**» |
| 6 `cases` | «**найдено 1 кейс**» |
| 10 `compose` | «из 1 фрагментов» |
| 11 `verify` | «утверждений 2 · покрыто 1 · 1 отброшено (нет цитаты) · уверенность 0.89 · ОГОВОРКА (medium)» |

**Ответ:**

> «По практике, регламент этот вопрос не покрывает: первичные бухгалтерские
> документы хранятся пять лет со дня составления [1].»

Пометки: `practice_only: true`, «по практике, регламент не покрывает».
Цитата — на `case-0001` (`source_kind: case`), а не на документ.

**Что доказывает этот критерий:** система не «выучила корпус» — она **запомнила
ответ человека** и теперь отвечает по нему, честно называя это практикой, а не
нормой.

## Что проверять в каждом дубле

1. Номер заявки и номер тикета — **новые** (в кадре не должно быть вчерашних).
2. Цитаты — из `corpus-real`, дословно; при двух цитатах — два разных `doc_id`.
3. Оговорка (`medium`) на месте, текст ответа не вырезан.
4. В кадре нет адресов, кроме `example.invalid`, и нет ключей.
5. Время акта А уложилось в тайминг из `docs/DEMO-CHECKLIST.md` §4.
