### C. UI — две колонки, обсидиан, анимация

```
+--------------------------------------+-------------------+
|  UI Lex                              |  Console Lex      |
|  красивое анимированное окно чата    |  шаги агента      |
|  агента: вопрос → ответ → цитаты     |  в понятной форме |
|  2/3 ширины                          |  1/3 ширины       |
+--------------------------------------+-------------------+
```

**Console Lex** показывает понятным языком, не JSON:
`принятие запроса` → `разбор на подвопросы` → `поиск: найдено N` →
`проверка прав: отброшено M` → `выбор действующей редакции` →
`сборка ответа` → `самопроверка`. Каждый шаг — свой цвет.

Это же — главный кадр для критерия «Агентность» (0 баллов за один запрос,
3 за видимый многошаговый цикл).

## 3. ⚠️ Открытый риск: «изолированный контур»

**Офиц. №8:** «решение должно работать с моделью, размещаемой во внутреннем
контуре... **локально развёрнутую модель, а не обращение к внешнему LLM API**.»
**Офиц. №11:** «само решение, в том числе демонстрацию жюри, должно происходить
в изолированном контуре.»

**Факт (подтверждён MERC, sage-pl, 26.11):** слот `claude-sonnet-5` — прокси в
OpenRouter. Локальных весов на sage-pl нет, GPU нет (CPU-сервер, 3.1/3.8 ГБ RAM),
vLLM/llama.cpp не установлены.

**Значит:** наш инференс — обращение к внешнему LLM API, пусть и через свой шлюз.
Формулировка «локальная модель» в документах **неверна** и должна быть убрана.

**Решения владельца:** локальную LLM не поднимаем, идём как решено.

**Что делаем вместо спора:**
1. Убрать «локальная модель» из описания продукта во всех файлах.
2. Честная формулировка: «LLM — NexusLink на сервере команды (sage-pl),
   маршрутизация слотов; эмбеддинги и реранкер — полностью локальные
   (bge-m3, bge-reranker-base, CPU); стоимость запроса 0».
3. Аргументы в защиту: документы **обезличены заказчиком** (№13), вся обработка
   корпуса (чанкинг, эмбеддинги, реранк) — локально, наружу уходит только
   обезличенный фрагмент в промпте, стоимость 0.
4. **Спросить организаторов прямо** (самый дешёвый ход): «изолированный контур =
   физическая изоляция или отсутствие внешних LLM API?» Если физическая — узнаём
   в первый час, а не 28-го.
