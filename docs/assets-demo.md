# Иллюстрации демо-стенда

Векторные материалы оформлены в сдержанном линейном стиле Wikipedia Vector 2022.
Иконки используют `currentColor`, поэтому цветом можно управлять из интерфейса.

| Файл | Назначение |
|---|---|
| `src/web/assets/icon-answer.svg` | Ответ подтверждён регламентом: документ и галочка. |
| `src/web/assets/icon-quality.svg` | Запрос в службу качества: конверт и восклицательный знак. |
| `src/web/assets/icon-out-of-scope.svg` | Вне компетенции: щит и крест. |
| `src/web/assets/illustration-empty.svg` | Пустое состояние: документ, лупа и подсказка «Задайте вопрос по регламентам компании». |
| `src/web/assets/pipeline-11.svg` | Схема 11 этапов от приёма до проверки. |

Цвета этапов сверены с `src/lex/models.py` (`STEP_COLORS`) и светлой палитрой
`src/web/lex.css` (`--s-*`). В `src/web/app.js` `KEY_COLORS` не найден; CSS
ссылается на `--s-pink` для этапа `policy`, но токен не определён. Поэтому узел
`policy` использует `var(--s-pink, #54595d)`: если токен будет задан при встраивании
SVG, применится он; иначе остаётся нейтральный slate, без придуманного розового.

Для встраивания: использовать относительные URL `assets/<имя>.svg`; статусные
иконки можно окрашивать через CSS `color`, а схему показывать в контейнере шириной
до 1200 px, сохраняя пропорции.
