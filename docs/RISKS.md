# ИИкузница — топ-5 рисков спринта

**Статус:** PREP phase. Ранжировано по (вероятность × урон).
**Маршрутизация моделей:** основной путь — NexusLink (sage-pl); локальная
Qwen3-8B — fallback. См. `docs/MODEL.md`.

---

## 1. NexusLink (sage-pl) недоступен

**Вероятность:** средняя (внешний шлюз, живой конфиг, владелец — M.E.R.C.).
**Урон:** высокий — основной путь закрыт, качество прогонов падает на локальном fallback.

**Mitigation:**
- **Fallback готов заранее:** профиль `local` (Qwen3-8B на `:8080`) поднят и
  проверен до 26.11 09:30 — переключение конфигом, без правок кода.
- **Проверка в 10:15:** `sh demo/run-local.sh --require-inference` — проверяет оба пути.
- **Слот:** `NEXUS_LINK_MODEL` задан явно; дефолт `claude-sonnet-5` на sage-pl даёт 502.
- **Токен:** `incoming_token` из конфига шлюза; доступ — через M.E.R.C. (владелец NexusLink).
- **Честность:** в описании продукта локальная модель заявлена как fallback —
  переход на неё не является расхождением с заявленным.
- **Второй уровень:** Qwen3-4B Q5 (~3 GB), если 8B не тянет по VRAM.

---

## 2. Датасет пустой / не соответствует ТЗ

**Вероятность:** средняя (ТЗ 26.11 может дать неожиданный формат).
**Урон:** высокий — нельзя прогнать сквозной сценарий, теряем «Корректность реализации».

**Mitigation:**
- **Синтетика детерминирована заранее:** `python demo/gen-sample-corpus.py --count 20 --seed 20261126 --clean`
  — 27 документов, 92 вопроса, 3 конфликтующих правила (см. `docs/EVAL-HARNESS.md` §1).
- **Адаптер:** ingest параметризован — при реальном ТЗ правим парсер, не цепочку.
- **Проверка в 10:15:** `sh demo/run-local.sh` (preflight + 5 вопросов без LLM).
- **Решение по умолчанию:** synthetic-first, real-second.

---

## 3. Конфликт редакций не обрабатывается (логика §4)

**Вероятность:** низко-средняя (иерархия формализована, возможны edge-cases).
**Урон:** средний — теряем баллы по «Агентность» (конфликт — ключевой шаг цикла).

**Mitigation:**
- **Формализация:** 6 уровней + вес `f(уровень, дата, редакция, отмены, область)` (`docs/ARCHITECTURE.md` §4).
- **Корпус специально настроен на ловушки:** будущая редакция, три редакции одного
  правила, отказ вместо ответа (`docs/EVAL-HARNESS.md` §6).
- **Unit-тесты:** `resolve()` на кейсах из `questions.jsonl` (`kind = rule_asof`).
- **Fallback-логика:** не смогли выбрать → обоснованный отказ (§6), а не ошибка.

---

## 4. Время на инференс / уложиться в видео ≤ 3 мин

**Вероятность:** средняя (зависит от профиля; на NexusLink — сеть и лимиты, на fallback — GPU).
**Урон:** высокий — видео не влезает в 3 мин, теряем «Степень готовности».

**Mitigation:**
- **Замер до съёмки:** p50/p95 на 5 вопросах в 09:30; видео пишется одним дублем,
  поэтому сначала цифры, потом запись.
- **Кэш:** кэш эмбеддингов и ответов — повторный вопрос ~0.
- **Основной путь быстрый:** на NexusLink latency определяется сетью, а не VRAM.
- **План Б:** видео на `dev`-профиле, в описании — честно, какой профиль снят.

---

## 5. Публикация репозитория (Q10)

**Вероятность:** низкая. **Урон:** средний — без публичного репо теряем «Потенциал внедрения».

**Mitigation:**
- Репозиторий создан заранее: `github.com/ykbojak-alt/iikuznitsa-sprint`.
- **Проверка перед сдачей:** открыть в инкогнито, README читается.
- **Данные:** только синтетический корпус (вариант B из `IIKUZNITSA-REPO-AND-DESCRIPTION.md` §2).
- **Секреты:** `.env` в `.gitignore`; ключи NexusLink — только env, никогда в git.
- **Лицензии:** наш код — MIT (`LICENSE`); внешние компоненты (Qwen3-8B, bge-m3,
  bge-reranker-base — Apache-2.0) перечислены отдельно в `docs/COMPONENTS.md`.
