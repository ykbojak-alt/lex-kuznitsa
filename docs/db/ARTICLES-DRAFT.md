# Статьи базы знаний — указатель рабочего набора

Черновик заменён рабочим набором по реальному корпусу заказчика. Статьи лежат в `docs/db/articles/` (32 файла),
полный указатель с темами и классами документов — в `docs/db/ARTICLES.md`.

Смежные файлы:
- `docs/db/ARTICLE-TEMPLATE.md` — форма статьи (эталон);
- `docs/db/ARTICLES.md` — указатель рабочего набора;
- `docs/db/DB-ARCHITECTURE.md` — схема базы (поля, типы, content_type, кейсы, формы, контракт ответа; в реальном корпусе нет rule_key, business_line и conflict_rules — редакций правил нет, поэтому «действующая редакция» не применяется);
- `demo/check-articles.py` — проверка набора по `corpus-real/manifest.json`.

Файл сохранён, потому что на него ссылается докстринг `src/lex/policy.py` как на
источник синонимов для определения направления. Правило прежнее: статья —
навигационная карта, ответ берётся из документа-источника.

Каталоги `dataset/` и `corpus-real/` с документами заказчика в публичный репозиторий
не попадают (см. .gitignore); в статьях нет нормативных значений.
