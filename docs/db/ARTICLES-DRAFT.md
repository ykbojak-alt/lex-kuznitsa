# Статьи базы знаний — указатель рабочего набора

Черновик заменён рабочим набором. Статьи лежат в `docs/db/articles/` (32 файла),
полный указатель с темами и классами документов — в `docs/db/ARTICLES.md`.

Смежные файлы:
- `docs/db/ARTICLE-TEMPLATE.md` — форма статьи (эталон);
- `docs/db/ARTICLES.md` — указатель рабочего набора;
- `docs/db/DB-ARCHITECTURE.md` — схема базы (поля, типы, редакции, content_type, кейсы, формы);
- `demo/check-articles.py` — проверка набора.

Файл сохранён, потому что на него ссылается докстринг `src/lex/policy.py` как на
источник синонимов для определения направления. Правило прежнее: статья —
навигационная карта, ответ берётся из документа-источника.
