# Тема: Как выбрать действующую редакцию правила

## Синонимы / как спрашивают
- «какая редакция действует», «на какую дату действует правило»
- «вчера было по-другому, сегодня иначе — почему», «будущая редакция»

## Суть
Правило в базе — это несколько редакций одного документа. Применимая редакция
выбирается по дате отсчёта: берётся последняя редакция, чья дата вступления в силу не
позже даты отсчёта. Если ни одна не действует — правило на эту дату не применяется,
и это честный отказ, а не «взять самую свежую».

Ответ берётся из документа-источника, не из этой статьи. Если источника с таким
классом в базе нет — агент обязан сказать, что ответа нет, а не собирать из статьи.

## Что искать в базе
- Ключ правила (rule_key) — все редакции одного правила.
- Поля редакции: номер редакции, дата вступления в силу, дата замены предыдущей.
- Раздел «Приёмочные критерии» правила — там записано правило выбора.
- Термины: редакция, действует, вступил в силу, заменяет, дата отсчёта.

## Где искать
- Класс документа: регламент с видом «редакция правила».
- Поля/признаки: rule_key, effective, revision.
- Что считать источником истины: выбранная редакция — она и есть норма.

## Чего в базе НЕТ
- Переходных и временных положений («на период с … по … действует …») — нет.
- Правил об отмене редакции задним числом — нет.

## Типичные ловушки
- Будущая редакция лежит в базе рядом с действующей — её применять нельзя.
- Разные редакции одного правила могут лежать в разных подразделениях: выбор по
  дате, а не по подразделению.
- Если в вопросе нет даты — дату надо уточнить у сотрудника.

## Пример вопроса
- Пользователь: «Какой срок согласования сейчас?»
- Ожидаемый ход поиска: правило по теме, затем выбор редакции по дате отсчёта.
- Ожидаемый вид ответа: значение из выбранной редакции с её номером и датой вступления;
  при отсутствии действующей редакции — честный отказ о неприменимости правила.

## Примеры в демо-корпусе
- В демо-корпусе правила: SR-01 (3 редакции), SR-02 (2 редакции), SR-03 (2 редакции) —
  демо-корпус, будет заменён.
