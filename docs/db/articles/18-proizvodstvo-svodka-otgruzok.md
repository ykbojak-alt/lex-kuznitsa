# Тема: Подготовка сводки по отгрузкам

## Синонимы / как спрашивают
- «сводка по отгрузкам», «отчёт по отгрузкам», «как готовить сводку отгрузок»
- «выгрузка отгрузок», «сводка отгруженного»

## Суть
Класс документов — инструкции «подготовки сводки по отгрузкам». Это отчётная процедура
внутри подразделения: что собрать, в каком виде и куда сохранить. Норм о сроках
поставки в этом классе нет.

Ответ берётся из документа-источника, не из этой статьи. Если источника с таким
классом в базе нет — агент обязан сказать, что ответа нет, а не собирать из статьи.

## Что искать в базе
- Название класса: «подготовки сводки по отгрузкам».
- Вид документа: инструкция.
- Поля: подразделение, контур, дата введения.
- Термины: отгрузка, сводка, отчёт, выгрузка, результат, исполнитель.

## Где искать
- Класс документа: инструкция.
- Поля/признаки: вид документа, подразделение, контур.
- Что считать источником истины: сама инструкция; смежные документы по отгрузкам
  в базе не найдены.

## Чего в базе НЕТ
- Формата сводки и утверждённой формы выгрузки — нет.
- Периодичности и сроков подачи сводки — нет.
- Правил сверки сводки с учётной системой — нет.

## Типичные ловушки
- Сводка по отгрузкам и сводка по отгрузкам за период — разный объём данных, но
  отдельного документа про период нет.
- Не путать с регламентом эскалации задержки поставки: там про срыв, тут про отчёт.

## Пример вопроса
- Пользователь: «Как готовится сводка по отгрузкам?»
- Ожидаемый ход поиска: класс «подготовки сводки по отгрузкам», фильтр по виду.
- Ожидаемый вид ответа: шаги и требования к результату из документа; формат и периодичность
  — пробел, если в документе их нет.
