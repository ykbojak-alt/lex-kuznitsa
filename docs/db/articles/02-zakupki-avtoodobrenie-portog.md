# Тема: Автоматическое одобрение заявки (порог суммы)

## Суть
Класс документов — регламент «автоматического одобрения заявки», тоже редакция правила.
Внутри правила лежит порог суммы, ниже которого заявка одобряется автоматически.
Отдельно в базе лежат документы про закупку и суммы: искать нужно правило, а не любой
документ со словом «сумма».

Ответ берётся из документа-источника, не из этой статьи. Если источника с таким
классом в базе нет — агент обязан сказать, что ответа нет, а не собирать из статьи.

## Синонимы / как спрашивают
- «до какой суммы автоодобрение», «порог автоматического одобрения»
- «когда заявка одобряется автоматически», «какая сумма проходит без согласования»
- «сумма заявки», «стоимость заявки», «цена закупки без согласования»

## Что искать в базе
- Ключ правила (rule_key) этого класса.
- Название класса: «автоматического одобрения заявки».
- Поля: номер редакции, дата вступления в силу, значение правила.
- Термины: сумма, стоимость, цена, оплата, автоматическое одобрение, заявка.

## Где искать
- Класс документа: регламент с видом «редакция правила».
- Поля/признаки: rule_key, раздел «Правило <ключ>», дата вступления в силу.
- Что считать источником истины: редакция правила, действующая на as_of.
- Перед ответом по сумме конкретной заявки — сначала правило, потом значение из него.

## Чего в базе НЕТ
- Порядка автоматического одобрения: в базе нет описания, кто и как выставляет признак
  автоматического одобрения.
- Исключений из порога (например, для отдельных номенклатурных позиций) — нет.
- Связи порога с конкретными формами заявок, кроме упоминания формы заявки.

## Типичные ловушки
- Две редакции с разными порогами и разными датами вступления.
- Вопрос «какой порог» и вопрос «подойдёт ли моя сумма» — разные: во втором случае нужна
  сумма заявителя, её надо уточнить.
- Порог из другой темы (например, лимит закупки в чек-листе) — не путать с правилом.

## Пример вопроса
- Пользователь: «До какой суммы заявка одобряется автоматически?»
- Ожидаемый ход поиска: класс «автоматического одобрения заявки», редакция по as_of.
- Ожидаемый вид ответа: порог из документа с номером редакции и датой вступления;
  если в вопросе звучит «моя заявка» — сначала уточнить сумму.

## Примеры в демо-корпусе
- ТЗ-ЭКЗ-СР03-Р1, ТЗ-ЭКЗ-СР03-Р2 — две редакции правила (демо-корпус, будет заменён).
