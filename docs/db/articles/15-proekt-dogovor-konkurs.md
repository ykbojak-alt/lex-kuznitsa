# Тема: Договор с заказчиком и конкурсные процедуры

## Суть
Класс процесса — «договор с заказчиком»: подготовка, согласование и подписание. Отдельно
описан конкурсный сценарий: проект договора из конкурсной документации или проект по
форме заказчика, согласование внутри компании.

Ответ берётся из документа-источника, не из этой статьи. Если источника с таким
классом в базе нет — агент обязан сказать, что ответа нет, а не собирать из статьи.

## Синонимы / как спрашивают
- «договор с заказчиком», «кто готовит договор», «согласование проекта договора»
- «конкурс», «конкурсная документация», «проект договора по форме заказчика»
- «выиграли конкурс», «шаблон договора из конкурсной документации»
- «когда можно стартовать работам без договора»

## Что искать в базе
- Класс документа: разделы подготовки, согласования и подписания договора с заказчиком,
  заключения договора.
- Артефакты: проект договора, заявка на согласование договора, конкурсная документация,
  гарантийное письмо.
- Роли: аккаунт-менеджер, юридический департамент, руководитель проекта.
- Термины: договор, конкурс, согласование, подписание, старт работ.

## Где искать
- Класс документа: разделы о договоре с заказчиком в регламентах проектной деятельности.
- Поля/признаки: кто готовит, кто согласовывает, маршрут согласования, исключения.
- Что считать источником истины: раздел о договоре той дирекции, которая ведёт сделку.
- Соседние шаги: старт проекта, инициация, регистрация проекта.

## Чего в базе НЕТ
- Шаблонов договора в базе нет: они берутся из конкурсной документации или формы
  заказчика.
- Регламента согласования договоров внутри компании в базе нет — описан только порядок
  запуска согласования.
- Типовых условий договоров в базе нет.

## Типичные ловушки
- Конкурсный сценарий описан только в одном регламенте — переносить его на другие
  дирекции нельзя.
- Шаблон договора в конкурсном сценарии берётся из конкурсной документации, а не из
  внутреннего шаблона.
- Гарантийное письмо — не договор: это исключение, разрешающее старт работ.
- Направление согласования внутри компании в разных регламентах различается.

## Пример вопроса
- Пользователь: «Кто готовит и согласовывает договор с заказчиком, что делать в
  конкурсном сценарии?»
- Ожидаемый ход поиска: определить дирекцию, найти раздел о договоре, прочитать роли и
  конкурсный сценарий.
- Ожидаемый вид ответа: порядок по найденному разделу с идентификатором документа; при
  отсутствии раздела о конкурсе — сказать, что в базе этого класса нет.

## Примеры в локальном корпусе
- КД-ПД-01 — раздел «7. Подготовка, согласование и подписание договора с Заказчиком»;
  КД-ПД-04 — раздел «8. Заключение договора с Заказчиком» (локальный корпус заказчика, в
  публичный репозиторий не попадает; пример, заменяемый реальной базой).
