# Тема: Порядок выполнения процедуры: общий шаблон шагов

## Синонимы / как спрашивают
- «как выполняется процедура», «порядок работы по заявке», «шаги обработки обращения»
- «как зарегистрировать обращение», «кто назначает исполнителя»

## Суть
Большинство документов корпуса описывают процедуру одинаково и в одном разделе —
«Порядок выполнения процедуры». Это сквозная механика обработки обращения, общая для
всех классов, а не отдельная тема. Ответ про шаги надо давать по разделу конкретного
документа, а не по общему шаблону.

Ответ берётся из документа-источника, не из этой статьи. Если источника с таким
классом в базе нет — агент обязан сказать, что ответа нет, а не собирать из статьи.

## Что искать в базе
- Раздел «Порядок выполнения процедуры» в нужном документе.
- Раздел «Роли и ответственность» — там про инициатора, исполнителя, руководителя.
- Раздел «Требования к оформлению результата» — что фиксируется по итогу.
- Термины: обращение, регистрация, комплектность, исполнитель, фиксация результата.

## Где искать
- Класс документа: любой документ корпуса; раздел внутри.
- Поля/признаки: контур (где регистрируется обращение), подразделение, ответственный.
- Что считать источником истины: документ, к которому относится вопрос.

## Чего в базе НЕТ
- Регламента, который задавал бы единый порядок для всех классов, — общий шаблон есть
  только внутри документов.
- Правил обработки некомплектных обращений и сроков их возврата — нет.

## Типичные ловушки
- Часть документов не нумерует шаги — тогда не выдумывать нумерацию, а опираться на
  текст раздела.
- Шаблон одинаков, но контур, роли и требования к результату у каждого документа свои.

## Пример вопроса
- Пользователь: «Как обрабатывается обращение в нашем процессе?»
- Ожидаемый ход поиска: определить класс по теме, открыть раздел «Порядок выполнения
  процедуры» и «Роли и ответственность».
- Ожидаемый вид ответа: шаги и роли из документа с идентификатором.

## Примеры в демо-корпусе
- В демо-корпусе пронумерованные шаги есть в 17 из 20 базовых документов; в 7 редакциях
  правил порядок описан словами — демо-корпус, будет заменён.
