# PLAN-48H.md — план 48 часов спринта ИИкузницы

Старт: 2026-11-26 10:00 (локальное время команды).  
Принцип: сначала работающий вертикальный срез, потом улучшение качества.

## Роли (условные)

- **ARCH** — архитектура, интеграция, технические решения.
- **DATA** — корпус, чанкинг, индекс, оценочный датасет.
- **ML/LLM** — модель, промпт, генерация, параметры.
- **UI/DEMO** — демо-стенд, UX, сценарий показа.
- **QA/METRICS** — прогоны, метрики, отчёт.

> Один человек может закрывать несколько ролей; задачи размечены для параллельной работы.

## Риски и буферы

- **VRAM/производительность:** держать fallback на меньший контекст/меньшую модель.
- **Качество retrieval:** буфер 4ч в 12–24.
- **Срывы интеграции:** вертикальный срез в первые 4ч обязателен.
- **Нет размеченного датасета:** честная мини-разметка + явные limitations.
